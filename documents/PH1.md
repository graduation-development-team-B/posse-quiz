## 提出・評価ルール

### 提出フロー（イシュー駆動開発）

1. **GitHub で Issue を立てる**（例：「Week01 プロフィールページ作成」→ `#1` が付く）
2. **Issue番号を使ってブランチを切る**
   ```bash
   git switch -c feature/1-week01-profile
   ```
3. コードを書いてコミット・プッシュ
4. **PR を作成**（チェックリストを埋める・PR本文に `Closes #1` を記載）
5. チェックリストを**全項目チェック済み**にしたら**自分でマージ**（Issueが自動クローズ）

合格基準：**PRのチェックリスト全項目がチェック済みであること**

再提出は同じPRに追加コミットするだけでOK（PRを閉じる必要なし）。

### ブランチ命名規則

```
feature/（Issue番号）-（週番号）-（一言説明）

例：
feature/1-week01-profile
feature/5-week03-flex-cards
feature/12-week06-bmi-calc
```

### PR本文に必ず書くこと（全週共通）

冒頭に Issue のクローズ宣言を入れてください。

```
Closes #（Issue番号）
```

続けて以下を記述します。

1. 使ったタグ/クラス/書き方を選んだ理由（3点以上）
2. 詰まった場所とどう解決したか（1箇所以上）
3. 【Week06以降・必須】AIに同じものを作らせて何が違うか比較

# Week01｜プロフィールページをGitHub Pagesで公開する

## インプット教材

- [Week01 インプット教材](./Week01.md)

## ミニドリル

週ファイル内のミニドリルセクションを参照してください。

- [Week01 ミニドリル](./Week01.md#ミニドリルai禁止45分)

## POSSE課題

自分のニックネーム・好きなこと・リンクをまとめたプロフィールページを HTML で作り、GitHub Pages で公開してください。「自分で作ったページをスマホで開ける・友達に送れる」状態がゴールです。

### 要件

- リポジトリ名: `my-profile`（SSH でクローンして作業する）
- 以下のタグをすべて使うこと: `h1`・`h2`・`p`・`ul/li`・`img`・`a`
- すべての `img` に `alt` 属性を書くこと
- Tailwind CDN を `<head>` に追加し、クラスを5つ以上使うこと
- GitHub Pages で公開し、URL をPR本文に記載すること

### ファイル名

`index.html`（`my-profile` リポジトリの直下）

### Step1. GitHubにリポジトリを作成してクローンする

GitHubにログインし、`my-profile` という名前でリポジトリを作成します。「Add a README file」にチェックを入れてから「Create repository」をクリックします。

作成したリポジトリをSSHでクローンします。

```bash
git clone git@github.com:あなたのユーザー名/my-profile.git
cd my-profile
```

VSCodeで開きます。

```bash
code .
```

### Step2. index.htmlを作成してHTMLを書く

`index.html` を新規作成し、HTMLの骨格から書き始めます。VSCodeで `!` + Tab キーを押すと骨格が自動入力されます。

`<body>` の中に自分のプロフィールを書いていきます。ニックネーム・好きなこと・リンクを入れてみましょう。

### Step3. Tailwind CDNを追加して見た目を整える

`<head>` 内に Tailwind CDN の `<script>` タグを追加します。追加したら各タグに Tailwind クラスを5つ以上つけて見た目を整えます。

> 本来 CDN 経由での読み込みは本番環境では推奨されていません。ただ、最初から複雑な環境構築をするより「まず動かして使ってみる」を優先したいので、今は CDN 経由で OK 👌 セットアップの本格的な方法は後の週で扱います。

### Step4. git pushしてGitHub Pagesで公開する

コードを書いたら Git でコミット・プッシュします。

```bash
git add index.html
git commit -m "プロフィールページを追加"
git push origin main
```

次に GitHub Pages を設定します。

1. GitHubのリポジトリページを開く
2. 「Settings」タブをクリック
3. 左メニューの「Pages」をクリック
4. Branch を `main` に設定して「Save」をクリック
5. しばらく待つと `https://あなたのユーザー名.github.io/my-profile/` でアクセスできる

PR を作成し、PR本文に GitHub Pages の URL を記載してください。

- [ ] Tailwind CDN の `<script>` タグを `<head>` に追加した
