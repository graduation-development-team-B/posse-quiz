# Week06 コード＋コンソール版

既存Week06クイズ15問を保持し、`week6.md` のミニドリル3題から18ステップを追加した。入口はWeek06の出題範囲画面。既存クイズの3/5/10問セッションと、順序付きドリルは別のボタンで開始する。

| ドリル | 6ステップ |
| --- | --- |
| 割り勘計算ツール | 合計の数値変換 → 人数の数値変換 → 割り算 → 切り上げ → 入力ガード → メッセージ |
| 型変換バグの修正 | バグと型の観察 → 合計の変換 → 人数の変換 → 演算の修正 → 切り上げ → 入力ガード |
| おやつ買い出しメモ | 単価の変換 → 個数の変換 → 掛け算 → 関数の戻り値 → 空入力 → 負数のガード |

## 教材からの変換方針

この追加版はJavaScriptの「入力→処理→出力」を扱う。元教材のHTML・Tailwind・クリックイベント・2カラムレイアウトは課題に含めず、フォーム入力を文字列のテスト値、画面表示をconsole.logに置き換える。BMIはPOSSE課題のため収録しない。

おやつ課題で教材が指定していない表示方針は、空入力・空白・負数を「入力を確認してください」、0を有効（小計0円）と定め、問題文に明記する。入力は教材に沿った数値文字列と空入力を対象とし、任意テキスト・Infinityなどの包括的な入力検証は発展課題とする。

## 実装

- `scripts/generate-week06-drills.js` が編集元。生成対象のIDのみを置換する。`question-week6-console-log-001` は既存クイズなので削除しない。
- 既存fillBlank形式にconsoleメタデータを追加（ドリルID・版・順序・完成コード・期待出力）。新しいステップでは直前までの正答を保持した足場コードを用意し、計算を関数にまとめる段階では足場を組み替える。
- 候補で編集 → 実行 → 出力確認 → 解答確定。正解のみ次ステップに進み、6ステップ正解で完了。実行後の編集は再実行が必要。
- Workerで実際のJavaScriptを実行し、console.logを収集。DOMやlocalStorageから切り離し、通信APIを無効化、1.5秒・60行・1行2000文字の上限を設定。終了・中止時にWorkerとBlob URLを破棄する。
- 実行対象は登録済みの固定コードと候補のみ。任意コードを受け付ける汎用サンドボックスではない。自由入力を導入する場合は実行環境の隔離を改めて設計する。
- 採点は実行成功・現在の入力との対応・指定候補・期待出力全行を確認する。現段階はクライアント採点。
- `progress:drill:<id>:v<version>` に完了数・入力を保存。復元後の実行結果は再実行して取得する。既存の「学習記録削除」で消去できる。
- Supabase移行時は定義と版、ユーザー別回答・作業状態を分離し、正式な採点と進捗更新をサーバー側に移す。コード・候補変更時は教材版も更新する。
